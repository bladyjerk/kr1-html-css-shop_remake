# Отчет по аудиту доступности (Accessibility Audit)

**Проект:** Интернет-магазин коллекционных реликвий «Tarnished Relics» (Elden Ring)  
**Репозиторий:** `kr1-html-css-shop_remake`  
**Стандарты:** WCAG 2.1 / 2.2 (уровень AA), WAI-ARIA 1.2, Lighthouse 13.6  
**Результат Lighthouse Accessibility:** **100 / 100** на всех 11 страницах  

---

## 1. Введение и цели аудита

В соответствии с заданием контрольной работы выполнены ключевые требования доступности:
1. **Проверка изображений и альтернативных описаний (`alt`):** семантическая точность для контентных изображений, устранение избыточного дублирования в скринридерах для декоративных элементов.
2. **Использование ARIA только там, где необходимо:** строгое следование первому правилу WAI-ARIA (*No ARIA is better than bad ARIA*), исключение конфликтов доступных имен (*Label in Name*) и ложных состояний.
3. **Lighthouse-аудит доступности:** полное тестирование всех 11 страниц проекта на движке Chromium.
4. **Сохранение отчетов и подтверждающих материалов:** сохранение интерактивных HTML-отчетов и скриншотов с максимальным баллом (100).

---

## 2. Выявленные проблемы и внесенные исправления

### 2.1. Альтернативный текст изображений (WCAG 1.1.1 Non-text Content)
- **Миниатюры в галерее товаров (`product-*.html`):** ранее имели пустой `alt=""` и избыточный `aria-label="Фото N"` на кнопках. Исправлено: кнопкам возвращена естественная семантика, изображениям назначен подробный `alt` (например, `alt="Маления, Клинок Микеллы — фото 1"`).
- **Синхронизация в JavaScript (`main.js`):** при смене ракурса в галерее обновлялся только `src`. Добавлено обновление доступного текста: `if (thumbImg) main.alt = thumbImg.alt;`.
- **Контентные изображения (`about.html`):** улучшено описание фото в секции истории мастерской: `alt="Коллекционная статуя Малении, Клинка Микеллы, с ручной росписью"`.
- **Декоративные превью в карточках (`catalog.html`, `index.html`):** оставлен пустой `alt=""`, так как наименование товара продублировано в соседней ссылке-заголовке. Это предотвращает повторное зачитывание скринридерами.

### 2.2. Коррекция ARIA и семантической структуры
- **Конфликт Label in Name на логотипе (WCAG 2.5.3):** убран искусственный `aria-label="Tarnished Relics — на главную"`, нарушавший совпадение видимого текста и доступного имени. Имя ссылки теперь формируется из текста `Tarnished Relics`.
- **Скрытие декоративной монограммы:** элементу `<span class="logo__mark">TR</span>` добавлен атрибут `aria-hidden="true"`, чтобы скринридеры не зачитывали технические буквы «TR».
- **Доступное скрытие текста логотипа в мобильной версии:** класс `.logo__text` переведен с `display: none` на стандартный паттерн `sr-only` (`clip: rect(0 0 0 0); width: 1px; height: 1px; position: absolute;`). Текст скрыт визуально на мобильных, но читается вспомогательными технологиями.
- **Удаление ложного состояния `aria-current`:** на страницах товаров (`product-*.html`) снят некорректный атрибут `aria-current="true"` со ссылки «Каталог».
- **Иерархия заголовков в каталоге (WCAG 1.3.1):** в `catalog.html` заголовки карточек изменены с `<h3>` на `<h2>` после главного заголовка страницы `<h1>`.
